# MediGuide AI

An AI-powered assistant that helps you understand medical reports, prescriptions, and health documents in plain, easy-to-understand language.

## Features
- Scan and interpret medical reports/prescriptions
- Ask health-related questions via AI chat
- Track medicine adherence and reminders
- Health analytics dashboard

## Tech Stack
- Frontend: React Native / Expo
- Backend: Python (FastAPI)
- AI: Claude / LLM integration

## Disclaimer
This is an educational tool only — not medical advice. Always follow your doctor's guidance.
